## 技术实现亮点

### 1. 设计系统
- Vercel 设计风格：简洁、现代、专业
- 统一左对齐布局基准线
- 响应式按钮和表单组件
- 成功/错误状态反馈 UI

### 2. 分段算法
- 优先按段落边界分割
- 段落过长时按句子分割
- 无标点文本强制按词数分割
- 支持 Markdown heading 分组（domain 包实现）

### 3. SRS 算法
- SM-2 兼容算法
- Ease factor 范围：1.3-∞
- 间隔天数：0 → 1 → 3/4 → 递增
- Mastery status：new → learning → reviewing → mastered
- 完整的 review_logs 记录

### 4. API 设计
- RESTful 风格
- 统一错误处理
- PostgreSQL 事务支持
- 软删除（deleted_at）
